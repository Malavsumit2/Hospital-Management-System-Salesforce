# 🏥 Hospital Management System - Salesforce

A complete **Salesforce Admin & Developer Project** that simulates a real-world Hospital Management System. This project demonstrates Salesforce Administration, Apex Development, Automation, Security, and Lightning Web Components (LWC) using Salesforce best practices.

---

## 📌 Project Overview

The Hospital Management System is designed to manage patient appointments, medical records, doctors, and hospital operations efficiently. It covers both Salesforce Administration and Salesforce Development concepts from beginner to intermediate level.
